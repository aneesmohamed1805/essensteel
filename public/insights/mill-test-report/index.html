What to Check in a Mill Test Report

How to check the report against your order and delivered material.

Match the report to the material

Start by matching the report identifier and batch or coil reference against the delivered material.

Check the results against the order

Compare the reported grade, dimensions and test results with the requirements in your purchase order and applicable standard. Ask the supplier to clarify any missing values or discrepancies before releasing the material for use.
